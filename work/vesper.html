Case study — Luxury e-commerce

Vesper

Luxury e-commerce has to feel premium and still handle real payments safely. Most student projects fake one or the other.

Role

Design system, UI design, full-stack build

Tools

Figma, Next.js 15, TypeScript, Stripe

Platform

The problem

Online luxury stores need to feel calm and expensive, but checkout and accounts still have to be secure and reliable — the feeling breaks the moment something goes wrong.

What made it hard

  • A shop and an admin panel that must feel like one product
  • Real payments with Stripe, not a fake checkout
  • Google sign-in and email accounts living side by side
  • Premium means restraint: few colours, lots of space

Three decisions

01

Design system before any page

I defined Vesper’s colours, type and components first, so every shop page and every admin screen is built from the same parts and feels the same.

02

Quiet, editorial storefront

A serif headline — “Objects made to outlast trend.” — strong photography and a single clear action. The design steps back so the product can lead.

03

Security is part of the experience

I found and fixed a session-merge flaw that could have given a Google sign-in user admin access, and added rate limiting to login. Trust is a UX feature.

What I learned

A design system is what lets one person keep a big product consistent. Doing it first felt slow, but every page after it was faster — and the admin panel didn’t become an afterthought.
